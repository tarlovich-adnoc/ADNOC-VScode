# Optimization log — the standing record the bi-weekly review fills

> One entry per review cycle (`ai/governance/README.md` → "Bi-weekly review cadence").
> This file IS the evidence that usage is reviewed and acted upon — keep the numbers in.
> If entries contain team-internal figures you can't share, gitignore the file and tell the
> CoE where the numbers live instead.

## Template (copy per entry)

```markdown
## YYYY-MM-DD

- **Numbers before:** <from dashboard.py / Copilot usage report — runs, est. spend, failure share>
- **Observation:** <e.g. agent X is 60% of estimated spend; ok:false share of Y at 25%>
- **Hypothesis:** <why>
- **Action:** <one concrete change: narrowed applyTo mask / split skill / demoted agent to opt-in /
  fixed top failure via /selfimprove / flagged premium-burn in org usage report>
- **Result (next review):** <numbers after — did it move?>
```
